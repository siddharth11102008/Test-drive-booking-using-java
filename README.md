🚗 Test Drive Booking System (Java)

This project is a vehicle test drive booking management system built using Java and MySQL.

Features:
- User registration and login
- Browse available vehicles
- Book vehicle test drives
- View booking history and booking status
- Submit feedback and reviews after completed test drive

Admin Features:
- Admin login
- Manage users
- Add, update, and delete vehicles
- Approve, reject, and complete bookings
- View customer feedback and reviews

Technologies Used:
- Java
- MySQL
- JDBC
- Swing / Java GUI
- File Handling

Purpose:
This project was developed as a diploma computer engineering academic project to demonstrate Java programming concepts such as OOP, database connectivity, CRUD operations, authentication, booking workflow, and user/admin role management.
